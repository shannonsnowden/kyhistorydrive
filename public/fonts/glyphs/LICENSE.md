# Map label glyphs

`Open Sans Semibold/` holds MapLibre SDF glyph ranges 0-255 (Basic Latin, Latin-1) and 8192-8447
(General Punctuation: en dash, curly quotes) for the Roads & Rails line labels, self-hosted so the map
makes no third-party font requests. Generated from Open Sans (Copyright 2020 The Open Sans Project Authors,
https://github.com/googlefonts/opensans), licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Glyph PBFs taken from the MapLibre demo tiles font set.
