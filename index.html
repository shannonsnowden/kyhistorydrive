KY History Drive

Kentucky historical markers on the road

Map About App

Find official Kentucky Historical Society markers while you drive — map, pins, and the story at the roadside. OpenStreetMap basemap via MapLibre (no Google Maps).

Tap a marker for details.

About

Marker text and locations come from public Kentucky Historical Society / history.ky.gov sources (geocoded for the KY Markers Drive project). This site is a web companion to the iOS app.

Maps: MapLibre GL JS + OpenStreetMap raster tiles (CARTO Voyager). Optional OpenHistoricalMap raster overlay. Production tile providers (MapTiler, Stadia, etc.) can replace the default style via env — see README.
